# Visual grammar reference

Use this to turn a direction into a coherent system.

## Typography
Choose type for voice and reading job, then establish contrast through role, size, weight, width, spacing and case. Do not compensate for weak hierarchy with more colors or boxes. Use the project's existing type system when present.

## Composition
Create dominant, supporting and quiet regions. Use alignment and spacing to express relationships. Repetition creates rhythm; deliberate breaks create emphasis. Empty space is structural, not leftover space.

## Color
Start from role and relationships: background/surface/text/accent/status, not a bag of swatches. Accent scarcity increases signal. Verify foreground/background pairs and themes. Brand color is not automatically the right color for every action.

## Shape and depth
Use radius, borders and elevation as a hierarchy. Nested surfaces should not become nested decoration. Use depth to explain layering/interaction, not to make every object “pop.”

## Imagery and icons
Choose one visual treatment and maintain it. Prefer existing iconography. Match stroke, fill, size and optical weight. Decorative imagery should support the North Star rather than fill empty space.
