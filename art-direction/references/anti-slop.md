# Anti-generic / anti-slop review

These are suspicion triggers, not universal prohibitions:
- generic gradient headline + glow + glass cards without subject-matter reason
- every section represented as a rounded card
- identical radius/elevation at every hierarchy level
- icon-in-colored-square decoration repeated without information value
- arbitrary badges/pills used as visual filler
- hero composition copied from category defaults despite a different brief
- excessive centered text
- too many competing accents
- default font/icon choices without checking the existing brand/system
- animation added to prove animation exists
- “premium” expressed only as dark background + gradients + blur

When one appears, ask whether the brief, system or interaction genuinely justifies it. If yes, keep it. If not, replace the default with a decision tied to the Creative North Star.
