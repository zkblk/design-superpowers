# Art Direction

Answer: **What coherent visual point of view should this surface express?**

Use only when visual direction is materially unresolved. Routine KPI/table/form work with an established visual language belongs elsewhere.

## Establish visual authority
Separate Preserve (confirmed identity/system), Open (genuinely unresolved), Reject (confirmed anti-references only). Refinement preserves the visual world; redesign may replace it.

## Surface mode
Identify dominant mode: Persuade, Operate, Read or Experience. Different surfaces may use different modes.

## Creative North Star
Write one concrete direction capable of rejecting alternatives, then set only relevant visual dials: expression, density, warmth, geometry, typography, depth, imagery, motion, brand presence.

## Coherent grammar
Make mutually reinforcing decisions across typography, composition/rhythm/whitespace, palette, shape/radius, borders/surfaces/depth, imagery, icons and motion. Prefer a few strong repeated decisions over unrelated flourishes.

## Anti-generic test
Challenge unexamined defaults: gratuitous gradients/glows, excessive rounded/card-within-card layouts, uniform radii, random pills, decorative icon boxes, weak hierarchy, centered-everything, generic hero formulas, arbitrary shadows/glass, over-animation and default typography/icons. These are warnings, not bans.

## Bounded critique
Build coherent pass → inspect actual rendered sizes → identify highest-leverage weaknesses → one batch fix → confirm once → stop unless material problem remains.

Project-specific taste belongs in project memory, not universal rules. Load only needed files from `references/`. Return direction and implementation implications to Director.
