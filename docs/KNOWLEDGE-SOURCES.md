# Knowledge Sources

Rule cards are original synthesis, not copied component documentation.

Authority anchors used for V1:
- W3C WAI-ARIA Authoring Practices: interaction semantics, keyboard/focus patterns and native-semantics cautions.
- GOV.UK Design System: robust form/component usage, errors, labels, dates and service interaction defaults.
- GitHub Primer: data-table anatomy, comparison/scanning, numeric alignment, responsive/accessibility behavior.
- IBM Carbon Design System: data-visualization purpose taxonomy and chart anatomy.
- Adobe Spectrum: component anatomy/states and platform-agnostic control guidance.
- Nielsen Norman Group and established usability literature: behavioral heuristics, icon/label discoverability and interaction clarity.

Precedent galleries and social-media tips are intentionally lower authority and cannot create MUST rules.

When sources disagree, prefer: measured project/domain evidence → standards/native semantics → mature explicit design-system guidance → research literature → precedent/taste.
