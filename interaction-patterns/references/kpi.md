# KPI / Metric Card Contract
A KPI exists to answer a decision question, not merely display a number.
Check: decision/question; primary value + unit; period; comparison baseline; delta direction semantics; target/threshold/status if meaningful; trend only when useful; freshness; drill-down/action; missing/loading/error; accessible text equivalent for visual trends; responsive priority.
Avoid unexplained percentages, ambiguous green/red semantics, decorative sparklines, mixed time windows and cards with equal visual emphasis when priorities differ.
