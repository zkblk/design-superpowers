# KPI / Metric Card
A KPI answers a decision question, not merely displays a number.
**MUST** Never invent comparison, trend, target, status, confidence or history absent from data/requirements.
**DEFAULT** Primary measure dominates; unit and period/scope are unambiguous; comparison appears only when a meaningful baseline exists and is named.
**CONTEXTUAL** Add trend only when actual history exists and helps the decision; add target/progress only when a target exists.
**MUST** Positive/negative meaning comes from domain semantics, not numeric direction alone.
**AVOID** fabricated sparklines, unexplained percentages, redundant icons, color-only status and chrome dominating the metric.
Verify missing/zero/null, formatting, extreme values, comparison semantics, freshness and narrow layout.
