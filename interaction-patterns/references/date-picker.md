# Date Picker
First decide whether users need direct text entry, calendar selection, a range, date+time, or a constrained set of dates. Do not force a calendar for values that are faster/safer to type.

Define: locale/format, input parsing, current/selected/focused dates, min/max, unavailable dates, single/range behavior, month/year navigation, validation/recovery, keyboard/pointer interaction, responsive/mobile presentation, timezone implications when relevant, and accessible labeling/instructions.

Test boundary dates, invalid input, unavailable dates, long locale formats, narrow viewport, keyboard-only navigation, focus return/dismissal, and error communication.
