# Filters
Filters reduce a dataset by attributes; search matches a query.
**MUST** Active filters are visible and reversible.
**DEFAULT** Prioritize common filters and progressively disclose rare ones.
**CONTEXTUAL** Apply immediately when cheap/fast/reversible; use Apply when choices form a staged query or computation is expensive.
**DEFAULT** Provide reset/clear when multiple filters accumulate.
**AVOID** hidden active filters, unexpected resets, duplicate search/filter semantics and implementation-jargon labels.
