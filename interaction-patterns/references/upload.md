# File Upload
Define accepted type/size/count, selection/drop/paste methods where appropriate, pre-upload validation, progress, cancellation/retry, duplicate handling, success/error per file, destructive removal, privacy/security messaging supplied by the product, and post-upload state.

Do not invent backend capabilities. A drop zone must not be the only operable method. Provide an accessible control/name/instructions and text-based status/error feedback. Test empty, one file, multiple files, oversized/invalid files, network failure, partial failure, retry and narrow viewport.
