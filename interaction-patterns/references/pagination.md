# Pagination
**DEFAULT** Use when a dataset is too large for one manageable view and stable chunks/locations help.
**MUST** Communicate current position and preserve relevant search/filter/sort state.
**CONTEXTUAL** Use links when pages map to URLs; buttons when controls only replace application data.
**DEFAULT** Choose page size from density, complexity, performance and context needs, not a magic number.
**AVOID** tiny pages, overwhelming pages and unrelated state resets.
