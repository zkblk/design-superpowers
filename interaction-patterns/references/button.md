# Button

**MUST** Use a button for an action; use a link for navigation when a destination/URL is the semantic outcome. Preserve a clear accessible name and keyboard/focus behavior.

**DEFAULT** Use a specific verb label that describes the outcome. Keep one visually dominant primary action per local decision area; demote secondary actions rather than making every action prominent.

**DEFAULT** Prefer text labels. Add an icon only when it improves recognition, communicates a conventional action, or is required by space/context.

**CONTEXTUAL** Icon-only buttons are appropriate for strongly conventional, repeated compact controls when an accessible name exists and the meaning is clear in context.

**AVOID** decorative icons on every button, vague labels ("OK", "Submit") when a specific action is available, disabled actions without explanation when users need to know how to proceed, and changing layout when a button enters a short pending state.

Verify: semantics, label/outcome match, hierarchy, target size, focus, disabled/pending behavior, destructive-action safety.
