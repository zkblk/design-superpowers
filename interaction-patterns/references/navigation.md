# Navigation
**DEFAULT** Organize around recognizable objects/tasks, not internal org structure. Labels should predict destinations.
**DEFAULT** Keep primary navigation stable and genuinely primary; progressively disclose secondary areas.
**MUST** Current location is perceivable without color alone; keyboard/focus behavior is complete.
**CONTEXTUAL** Sidebar/top nav/tabs/breadcrumbs/local nav solve different scope/depth/frequency problems.
**AVOID** unfamiliar icon-only primary nav, ambiguous action-vs-destination mixing and hiding frequent destinations unnecessarily.
