# Validation and Errors
**MUST** Explain what is wrong and how to recover; associate the message with its control; preserve valid input.
**DEFAULT** Validate when feedback helps rather than interrupts. Submit-time is robust for many forms; earlier feedback is useful after meaningful interaction when it prevents costly work.
**DEFAULT** Put errors near their source; for long/multi-error forms add a summary that leads to problems.
**MUST** Do not rely on color alone.
**AVOID** generic "Invalid input", premature red states while typing, duplicate messages, or disabled submit with no explanation.
