# Choose a Chart
Start from the analytical question and data shape, not aesthetics.
Ask: what must be learned/decided; relationship (comparison, trend, distribution, correlation, part-to-whole, connection/hierarchy, geospatial); field types; number of series/points; precision needed.
**DEFAULT** time trend→line; discrete magnitude comparison→bar; quantitative relationship→scatter; distribution→histogram/box/dot; composition→often stacked bar; single value→text/KPI.
**MUST** Never manufacture data to satisfy a chart type.
**AVOID** 3D, decorative chart selection, unjustified dual axes, and charts when text/table answers more directly.
