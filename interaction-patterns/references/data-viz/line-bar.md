# Line and Bar
## Line
**DEFAULT** Change/trend across ordered continuous dimensions, especially time. Preserve order. Limit overlapping series.
**AVOID** connecting unrelated categories.
## Bar
**DEFAULT** Compare magnitudes across discrete categories. Use a meaningful zero baseline when length encodes magnitude. Sort by value for ranking; preserve natural order when sequence matters.
**CONTEXTUAL** Grouped bars compare a few series; stacked bars emphasize totals/composition but weaken non-baseline comparison.
For both: units, missing values, manageable series and small-screen legibility.
