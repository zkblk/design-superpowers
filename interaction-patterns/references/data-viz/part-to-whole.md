# Part-to-Whole
First ask whether the task is composition or precise category comparison.
**DEFAULT** Prefer stacked bars when comparison across parts/groups matters.
**CONTEXTUAL** Pie/donut can communicate a simple whole with few clearly different parts when approximate composition is enough.
**MUST** Parts map to a meaningful whole/denominator.
**AVOID** many/similar slices, 3D pies, multiple pies for comparison and decorative donut semantics.
