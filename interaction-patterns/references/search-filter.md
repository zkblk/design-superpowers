# Search & Filter
Separate retrieval intent from refinement. Search finds by query; filters constrain a result set; sorting changes order.

Define query timing/submit model, clear/reset, applied-filter visibility, counts where meaningful, empty/no-result distinction, persistence, URL/share state where product architecture supports it, loading/error behavior, keyboard/focus, responsive presentation, and whether filters need drawer/popover/inline treatment.

Preserve user context when feasible. Make it obvious why a result set changed and how to return to the broader set.
