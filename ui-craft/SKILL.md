# UI Craft

Answer: **How should this already-defined solution be visually composed and refined?**

Hierarchy before decoration. System before local values. Existing project conventions beat generic heuristics.

Inspect current tokens, type styles, grid/layout, components, icon set and responsive conventions before introducing anything. Use spacing/type/color/radius/elevation/motion scales consistently. Treat common numeric grids/ratios as optional heuristics, never laws.

Use proximity, alignment, whitespace, contrast and grouping to express relationships. Internal/external spacing should communicate containment and hierarchy without forcing a formula over the project system.

Design responsive behavior concurrently: stretch, wrap, stack, truncate, scroll, priority changes, min/max sizes and what must remain visible.

Avoid arbitrary card piles, gratuitous gradients, excessive rounding/shadows, random decorative motion and inconsistent local styling. If the unresolved problem is the visual point of view itself, return to Director for `art-direction`. If the change belongs in reusable tokens/components, return it for `design-system`.
