# UI Craft

Hierarchy before decoration. System before local values. Existing project conventions beat generic heuristics.

Inspect current tokens, type styles, grid/layout, components, icon set and responsive conventions before introducing anything. Use spacing/type/color/radius/elevation/motion scales consistently. Treat 4/8pt grids, modular type scales, rule-of-thirds, golden ratio and 60/30/10 as optional heuristics, never universal laws.

Use proximity, alignment, whitespace, contrast and grouping to express relationships. Internal/external spacing should communicate containment and hierarchy, but do not force a numeric formula over the project's system.

Responsive behavior is designed concurrently: define stretch, wrap, stack, truncate, scroll, priority changes, min/max sizes and what must remain visible. Avoid fixed layouts that only work at the authored viewport.

Avoid generic AI slop: arbitrary card piles, gratuitous gradients, excessive rounding/shadows, random decorative motion and inconsistent local styling. Distinctiveness should come from context/brand direction, not novelty for its own sake.

Accessibility and design-system compliance are construction constraints, not final polish.
