# Typography
**MUST** Reuse project type family/tokens/semantic styles when available.
**DEFAULT** Use a limited hierarchy with meaningful size/weight/spacing differences; prioritize readability and clarity.
**DEFAULT** Use tabular numerals for vertically compared numbers when supported.
**CONTEXTUAL** Line length, line height and density depend on reading vs operational task and viewport.
**AVOID** arbitrary type values, excessive uppercase, low-contrast secondary text and shrinking type to solve layout that should reflow.
