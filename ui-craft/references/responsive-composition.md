# Responsive Composition
For each region decide: stretch, constrain, wrap, stack, reorder, collapse, scroll, truncate, or hide only if nonessential.
**MUST** Preserve task-critical content/actions and accessibility at narrow widths/zoom.
**DEFAULT** Let content pressure reveal transitions; reuse project breakpoints/tokens.
**CONTEXTUAL** Dense tables may scroll/prioritize columns rather than automatically becoming cards.
**AVOID** desktop shrinking, arbitrary hiding, tiny controls and meaning changes just to fit.
