# Density
Density is a task decision, not a style preference.
**DEFAULT** High-frequency scanning/comparison can justify compact layouts; comprehension/onboarding/touch contexts often need more space.
**MUST** Density cannot break target size, readability, focus visibility or distinction.
**DEFAULT** Change density systematically via tokens/component variants.
**AVOID** making UI "clean" by hiding required information or "enterprise" by compressing everything uniformly.
