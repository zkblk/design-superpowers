# Spacing
**MUST** Use project spacing tokens/scale when one exists.
**DEFAULT** Proximity communicates relationship: within-group spacing is smaller than between-group spacing; repeated structures use repeated rhythm.
**DEFAULT** Start from semantic grouping, then choose tokens.
**CONTEXTUAL** Dense operational UI can be tighter than reading/marketing surfaces while preserving hierarchy.
**AVOID** arbitrary one-offs, equal gaps at every hierarchy level, containers added only for padding, and treating whitespace as waste.
