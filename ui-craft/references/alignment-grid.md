# Alignment and Grid
**DEFAULT** Align related elements to shared edges/baselines; a few strong alignment lines beat many local centering decisions.
**MUST** Reuse project grid/container conventions when present.
**CONTEXTUAL** Optical alignment may differ from geometric alignment for icons/type/asymmetric shapes.
**AVOID** unrelated nested gutters, accidental near-alignment, centering dense operational content by default and inventing a new grid locally.
