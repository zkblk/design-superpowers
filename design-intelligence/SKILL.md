# Design Intelligence

Use psychology to explain observed or plausible mechanisms, not to decorate recommendations with named laws.

Layers: perception/salience/grouping → attention → comprehension/mental models → memory/cognitive load → decision/friction/motivation → action/feedback → remembered experience.

Use relevant Laws of UX and Gestalt principles as evidence-informed heuristics. Avoid pseudo-precision and universal numeric claims. Distinguish established accessibility/interaction requirements, broadly supported principles, useful heuristics and context-dependent hypotheses.

## Predictive attention mode
Estimate likely attention competition from hierarchy, size, contrast, position, proximity, grouping, motion and information density. Output a hypothesis/scan-path risk, never call it an actual heatmap or measured eye-tracking result.

## Behavioral hypothesis
State: observed/problem signal → plausible mechanism → intervention → expected behavior → measurement that could falsify it. Include autonomy/ethics; avoid deceptive or coercive patterns.
